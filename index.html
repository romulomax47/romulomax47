01 / SOBRE MIM

Movido pela curiosidade.
Guiado pela prática.

Sou o Rômulo, moro na região do Ipiranga, em São Paulo, e sou apaixonado por tecnologia. Estudo Análise e Desenvolvimento de Sistemas (ADS) e estou em formação para atuar com desenvolvimento full stack, com interesse especial em front-end.

HTML, CSS, JavaScript, jQuery, Bootstrap e MongoDB fazem parte das tecnologias que apresento no meu perfil. Meu foco é ampliar essa base com prática e transformar o aprendizado em projetos que eu possa compartilhar.

Antes dessa jornada, trabalhei como auxiliar mecânico. Hoje, estou construindo meu caminho no desenvolvimento de software e explorando as possibilidades da web.

Este portfólio é parte dessa trajetória: um site em HTML, CSS e JavaScript, com layout responsivo e integração com a API pública do GitHub para apresentar meus repositórios.
